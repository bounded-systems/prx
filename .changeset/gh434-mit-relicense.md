Relicense prx from `PolyForm-Noncommercial-1.0.0` to `MIT`, completing the #669
sweep for the runtime and unblocking the FlakeHub publishing surface.

`flakehub-push` defaults its `spdx-expression` to whatever GitHub reports as the
repo's `spdxIdentifier`. PolyForm-Noncommercial is valid SPDX but not
OSI-approved and not in GitHub's recognised set, so GitHub reported nothing and
a FlakeHub publish would have carried a null SPDX expression — one of the
concrete costs `.github-private` cited when #669 superseded #659's two-tier
split. The same nullity also cost the license badge, `pkg.go.dev` allowlist
inclusion, and clean crates.io metadata.

Sources changed, with every derived file regenerated by `bun run docs:render`:
`community/community.json`, the `license`/`readme`/`contributing` templates, both
package manifests, and the `claude-context` builder (which described the project
as "source-available", a phrase that is false under MIT).

Loosening a licence is irreversible per published version: `1.0.0` and earlier
remain under PolyForm; this version onward is MIT.
